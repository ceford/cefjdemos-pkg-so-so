# Joomla Language pack for Somali

This language pack was made by translation of the Joomla 5 English language pack using openai.com. The package can be installed as for any other extension, not as a language. The direct links for download are:

- Joomla 5: https://github.com/ceford/cefjdemos-pkg-so-so/raw/joomla5/downloads/pkg_so-SO-joomla5.zip

After installation, enable via System -> Content Languages, and then create a Menu and Menu item for the language.
